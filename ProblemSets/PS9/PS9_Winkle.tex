\subsection*{10}

\begin{enumerate}
    \item Would you be able to estimate a simple linear regression model on a data set that had more columns than rows? 
        \begin{itemize}
            \item[--] No. If $p>n$, then $(X'X)$ is singular. Therefore, $\hat{\beta} = (X'X)^{-1}X'y$ is not defined, because $(X'X)^{-1}$ does not exist. Thus, you cannot estimate a unique OLS linear regression when $p>n$.
        \end{itemize}

    \item Using the RMSE values of each of the tuned models in the previous two questions, comment on where your model stands in terms of the bias-variance tradeoff.
        \begin{itemize}
            \item[--] Both models reduce overfitting, but ridge achieves the slightly better bias-variance tradeoff here because it has the lower test RMSE. LASSO fits the training data slightly better, while ridge generalizes slightly better. This suggests LASSO has slightly lower bias and higher variance, whereas ridge accepts slightly more bias in exchange for lower variance.
        \end{itemize}
\end{enumerate}
