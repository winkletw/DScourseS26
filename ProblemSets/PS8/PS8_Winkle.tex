\subsection*{5}

\noindent The closed-form estimates are extremely close to the true $\beta$ values: $\hat\beta_{OLS}$ closely recovers the true parameter vector, with only very small deviations.

\subsection*{7}

\noindent The L-BFGS and Nelder-Mead estimates are nearly identical, but L-BFGS matches the closed-form OLS solution more precisely.  

\subsection*{9}

The estimates of $\hat\beta$ are very similar to the true $\beta$: OLS, gradient descent, L-BFGS, and MLE are essentially identical, and Nelder-Mead is also extremely close. Across coefficients, the estimated values differ from the true values by a few thousandths.
